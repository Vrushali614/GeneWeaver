# GeneWeaver User Guide

## 1. Starting the application
Open a terminal in the GeneWeaver project directory and activate the project's virtual environment. Install dependencies if they have not already been installed.

## 2. Providing sequence input
Provide the guide RNA sequence and target DNA sequence using the format accepted by the program. Remove unsupported characters and confirm whether the application expects DNA or RNA notation.

## 3. Validating input
Run the validation step. If an error is displayed, check the sequence symbols, empty fields, and file format.

## 4. Running alignment
Start the alignment operation using the application's actual run command or interface. If a compatible GPU backend is configured, the application may use it for supported operations; otherwise use the CPU path if provided.

## 5. Reading results
Review the output generated by the program. Depending on the implemented algorithm, this may include aligned sequences, match/mismatch positions, alignment score, or processing information. Do not assume a field is available unless it appears in the application.

## 6. Example workflow
Open application → enter guide sequence → enter target sequence → validate → run alignment → review output.

## 7. Safe use
Treat results as computational predictions only. Verify scientific interpretations with appropriate bioinformatics references and qualified supervision. Do not use this prototype as a clinical decision tool.
